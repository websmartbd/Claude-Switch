Engineered for heavy Claude power users

Everything is local to your browser profile. No cloud backends, no tracking, and no cookie leaks.

Instant Hotkey Switching

Switch active accounts in one keystroke using Ctrl+Shift+1..9 directly while typing inside the chat composer.

Intelligent Limit Engine

Automatically detects lockouts, parses "until tomorrow at 3:40 AM" notices, and synchronizes live countdown bars across all open tabs.

Desktop Push Notifications

Background alarms track the exact reset timestamp. Get a desktop notification the second an account is ready so you never miss a quota cycle.

Optional AES-256 Encryption

Protect stored session tokens behind an optional master passphrase with PBKDF2-SHA256 (600,000 iterations) and AES-GCM.

Cloudflare Clearance Protection

Preserves your active Cloudflare clearance cookies during switches, avoiding annoying captcha loops or repeated device checks.

Discrete In-Page Pill

Renders inside a closed Shadow DOM directly in Claude's navigation header. Zero CSS interference with Claude's native stylesheet.

How it works under the hood

Clean architecture built strictly on official Chrome Extension APIs.

1

Session Virtualization via Cookie Jar

When switching, the active cookies (sessionKey, org identifiers, device preferences) are snapshotted into local encrypted storage, and the target account's cookie state is atomically restored into the browser partition.

2

DOM Mutation Observer & Support Link Detection

Instead of heavy periodic scans, a debounced MutationObserver watches for Claude's rate-limit banners and support articles, normalizing time offsets and computing the exact millisecond expiry timestamp.

3

Chrome Alarms & Native Desktop Dispatcher

The background service worker schedules precise alarms via chrome.alarms. When the timer triggers, an OS-level notification alerts you with the specific account nickname and tier.
